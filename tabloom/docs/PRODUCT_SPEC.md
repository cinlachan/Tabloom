# Tabloom 产品与交互规格

## 1. 产品定位

Tabloom 是面向“经常同时打开大量网页”的用户设计的标签页工作台。它不只是展示当前标签页，还帮助用户区分三类状态：现在正在使用、稍后需要处理、值得长期保留。

产品名：**Tabloom**（Tab + Loom）

品牌语：**Keep tabs clear. Save what matters.**

## 2. 核心原则

1. 信息优先：用户应一眼看清网页标题、摘要、网站和当前状态。
2. 状态独立：`For Later` 和 `Saved` 不依赖标签页是否仍然打开。
3. 操作就近：单项操作放在网页行右侧，批量操作放在对应区块右上方。
4. 风险可控：能完整撤销的操作直接执行并提供撤销；只有关闭标签页这类不能完美复原的批量操作才弹确认。
5. 保留网页原貌：网页标题和摘要保持网页自身语言，不进行翻译。
6. 本地优先：当前版本不依赖账号和后端，数据只保存在浏览器本地。

## 3. 页面信息架构

三个区块必须按纵向从上到下排列，不能改为左、中、右三栏：

1. `For Later`
2. `Open Tabs`
3. `Saved`

每个区块包含：

- 折叠/展开按钮
- 区块名称与数量
- 一句状态说明
- 操作反馈与图标式 Undo
- 撤销胶囊（仅在可撤销时出现，紧贴批量按钮）
- 区块级批量操作
- 按网站聚合的卡片

### 3.1 顶栏与设置

- 顶栏只放：Logo、筛选框、`Jump to`、设置齿轮。不放刷新按钮，页面随标签页和存储变化自动刷新。
- 设置面板（齿轮打开，点空白或 `Esc` 关闭）：主题 / 音效 / 语言分段按钮，`Auto-sleep` 下拉，页面内快捷键，浏览器全局快捷键。
- 网站卡片的站点级操作（Complete / Close / Remove site）放在卡片标题栏右侧，hover 或聚焦时出现；卡片底部只在超过 4 条时显示「+N more」。
- 行内操作按钮默认隐藏，hover 卡片淡显，hover 行或键盘聚焦时完全显示；触屏设备始终显示。

## 4. For Later

用途：保存当前没时间处理、之后需要阅读、回复或完成的网页。

- 从 Open Tabs 点击时钟图标加入。
- 即使原标签页关闭，条目仍然保留。
- 点击条目：如果网页仍打开，切换到原标签页；否则重新打开 URL。
- 勾选表示处理完成，并从本区移除。
- 单项操作：打开、标记完成、收藏。
- 网站级操作：`Complete site`。
- 全部操作：`Complete all`，直接执行，可撤销（不再弹确认）。
- 撤销：恢复刚移除的条目。
- 时间淡化：按加入时间分为 fresh（<3 天）、aging（3–7 天）、wilting（7–14 天）、withered（≥14 天）。左侧琥珀色细条逐级加深，页面内容逐级变淡；hover/聚焦时恢复。状态行显示「Added 5 days ago / 5天前加入」。
- 有页面搁置超过一周时，区块说明改为提醒文案并显示琥珀色。
- 提醒：条目的时钟按钮打开下拉菜单，可选「今晚 / 明天早上 / 下周一」，也可清除。到期后该行显示「Reminder came due」并高亮；后台同时设置工具栏角标并发送一条系统通知，点通知打开 Tabloom，打开后角标清零。撤销会一并恢复原提醒。
- 「堆肥」提示：有页面在 For Later 里超过两周时，区块顶部显示堆肥提示，包含插画、一句说明和三个选择——`Move to Saved`、`Let them go`、`Not now`。选择后记录时间戳，一周内不再出现。

## 5. Open Tabs

用途：管理所有浏览器窗口中当前打开的网页。

- 数量与浏览器窗口数显示在区块说明中。
- 按网站聚合，相同网站的多个标签页放在同一卡片。
- 卡片显示网站 favicon/logo、网站名和标签页数量。
- 网页行显示原始标题与网页自身摘要。
- 单项操作：切换、加入 For Later、加入 Saved、关闭。
- 网站级操作：`Close site`。
- 全部操作：`Close all`，执行前确认；Tabloom 页面自身和固定（pinned）标签页不关闭。
- `Close site` 和命令面板「关闭某网站全部标签页」同样跳过固定标签页；单独点某个固定标签页的关闭按钮仍会关闭它。
- 固定标签页在行内显示「Pinned / 已固定」状态。
- 撤销：优先通过 `chrome.sessions` 恢复（保留历史）；浏览器已不记得的才按 URL 重新打开。
- 重复标签页：同一网址开启多份时，站点卡片数量旁显示「N dupes」胶囊，点击只关闭多出来的副本。保留优先级为正在使用 > 固定 > 最近访问，固定标签页不关闭。
- 窗口收起（Stash）：区块顶部按浏览器窗口列出收起按钮，把该窗口的全部标签页存成一组并关闭；组以胶囊形式显示数量与收起时间，可 `Restore`（在新窗口一次性恢复）或删除。两种操作都可撤销。
- 闲置休眠：顶部「Sleep idle tabs」把闲置超过 30 分钟的标签页卸载以释放内存，位置不变，点击即恢复，行内显示「Sleeping」。设置面板可改为自动执行（闲置 1 小时 / 4 小时）。正在使用、固定、播放声音、不可自动卸载的标签页以及非 HTTP(S) 页面一律跳过。

Open Tabs 是符合英语产品语境的名词短语，表示“当前处于打开状态的标签页”，不要改为 `Opened Tabs`。

## 6. Saved

用途：长期保留值得收藏的网页。

- 从 Open Tabs 或 For Later 点击书签图标加入。
- 原标签页关闭后仍然保留。
- 点击条目：切换到已打开标签页或重新打开 URL。
- 单项操作：打开、移除。
- 网站级操作：`Remove site`。
- 全部操作：`Remove all`，直接执行，可撤销（不再弹确认）。
- 移除收藏不应关闭正在打开的标签页。

## 7. 搜索

- 搜索范围：网页标题、摘要、网站名称和 URL。
- 搜索同时过滤三个区块。
- 页面内筛选：`/`（可修改）聚焦筛选框，`Esc` 清空。
- 无匹配内容时显示统一空状态，并提供 `Clear search`。

### 7.1 命令面板

- `⌘K`（Windows/Linux `Ctrl+K`，可修改）打开或关闭；顶部 `Jump to` 按钮同样可打开。
- 空输入时显示最近使用的标签页、For Later 前 3 条和全部命令。
- 输入关键词时按标题前缀 > 标题包含 > 网站名 > 摘要/URL 排序，所有关键词都必须命中；匹配片段高亮。
- 输入 `>` 前缀只显示命令。
- 键盘：`↑↓`/`Tab` 选择，`↵` 主操作，`⌘↵` 次操作，`⌘S` 收藏，`⌘⌫` 关闭或移除，`Esc` 先清空再关闭。
- 主操作（打开、执行命令）关闭面板；次操作保留面板，便于连续整理。
- 底部提示随选中项变化，只展示当前可用的操作。
- 除导航和整理命令外，还提供：关闭重复标签页、收起各浏览器窗口、恢复某个收起组、休眠闲置标签页、处理等了两周多的页面。停用状态的命令也会出现并说明原因（如「没有闲置够久的标签页」）。

### 7.2 全局收集

- 快捷键 `Alt+Shift+L` 加入 For Later，`Alt+Shift+S` 收藏，`Alt+Shift+T` 打开 Tabloom。
- 这三个快捷键只能在浏览器的扩展快捷键页修改，设置面板显示当前绑定并提供跳转入口。
- 右键网页或链接提供 `Keep … for later` / `Save …`。
- 成功、已存在、不可收集三种结果分别显示不同角标和页面内提示。新标签页、空白页和 Tabloom 自身不可收集。

### 7.3 撤销

- 每次移除、关闭、加入都会显示带 `Undo` 的 toast，持续 6 秒，悬停或聚焦时暂停。
- `⌘Z` / `Ctrl+Z`（可修改，不在输入框中时）撤销最近一次操作，各区块的撤销胶囊仍保留。

### 7.4 自定义快捷键

- 可修改：快速跳转、筛选、撤销。点击快捷键进入录制，按下新组合即保存；`Esc` 取消，`Tab` 退出录制。
- 允许单个按键（字母、数字、符号、F1–F12）或与 `⌘`/`Ctrl`、`Alt` 组合；单键在输入框中不触发。
- 拒绝：与其他页面快捷键冲突；`⌘`/`Ctrl` + A C F L N P Q R T V W X 等浏览器保留组合。
- 「恢复默认」一键还原。设置保存到 `keymap`，并同步到其他 Tabloom 标签页。
- 撤销关闭的标签页优先从浏览器最近关闭列表恢复。

## 8. 动效与声音反馈

- 声音模式：`Off`、`Subtle`、`Playful`，默认 `Subtle`。
- 完成、收藏、关闭、批量清理、撤销和折叠拥有不同的短反馈。
- 批量处理只播放一次组合声音，禁止为每个条目重复播放。
- 声音由浏览器本地实时生成，不加载外部音频、不联网。
- 系统开启“减少动态效果”时，跳过退出等待并关闭主要过渡动画。
- 搜索、刷新和普通网页切换等高频动作默认不播放声音。
- Logo 随打开标签页数量改变姿态：20 个以内盛开、超过 20 个花瓣下垂、超过 40 个收拢；hover 显示当前状态说明。
- 清空 For Later 时 logo 跳动一次、花瓣散开，并播放一段四音上行旋律；`Off` 模式无声，系统开启减少动态效果时不做位移。
- 三个区块的空状态各配一幅与 logo 同源的手绘插画（嫩芽、花苞、花、土堆），配色跟随主题。

## 9. 后续可扩展方向

- 为 For Later 添加截止日期、优先级和备注。
- 支持拖拽排序和自定义分组。
- 支持导入、导出和跨设备同步。
- 支持站点黑名单或仅按需读取网页摘要，以降低权限范围。
- Chrome Web Store 正式发布及隐私政策页面。
