# Tabloom 视觉与文案规范

## 1. 已确认的视觉方向

采用“精致深色工作台”的卡片层次与信息密度，同时默认跟随系统主题；系统为浅色时显示浅色背景，系统为深色时显示深色背景。用户可以手动覆盖为 Light 或 Dark。

布局规则：

- 桌面端完整页面，而非手机宽度弹窗。
- 三个业务区块保持上、中、下纵向结构。
- 每个区块横向铺满主内容区。
- 区块内部使用响应式多列瀑布流；网站卡片根据宽度显示三列、两列或一列，并在各列中紧密向下排列。
- 单张网站卡片默认最多显示 4 条网页，超出内容通过 `+ N more` 和 `Show less` 展开或收起。
- Open Tabs 卡片标题栏提供六点拖拽手柄；拖动时降低原卡片透明度，并用强调色描边提示放置目标。
- Open Tabs 支持手动、页面数量、最近活跃和网站名称排序；搜索状态下禁用拖拽。
- 主要断点：1180px 以下卡片两列；页面最低支持宽度为 900px。

## 2. 颜色变量

所有颜色集中在 `dashboard.css` 顶部的 CSS Variables 中。修改主题应优先调整变量，不要在组件中散落新的硬编码颜色。

品牌：紫色底板上的一朵手绘小花（取自小朋友的画）。界面只用一个强调色——紫罗兰；花瓣的粉橙色只出现在小的「惊喜时刻」。

浅色主题：

- 页面背景：`--bg: #f5f4f7`
- 区块内容底：`--well: #f8f7fa`
- 卡片背景：`--panel: #ffffff`
- 主文字：`--text: #1c1826`
- 次要文字：`--muted: #6a6578`（白底上满足 4.5:1 对比度）
- 品牌强调：`--accent: #6c3ad6`，`--accent-strong: #5a2bbf`，`--accent-soft: #f1ebfd`
- 花瓣点缀：`--petal: #ff7a59`（收藏火花、网页内提示圆点）
- For Later 淡化：`--later: #a8620b`
- 风险操作：`--danger: #c2424f`

深色主题：

- 页面背景：`--bg: #0f0d15`
- 卡片背景：`--panel: #1b1826`
- 主文字：`--text: #f3f1f8`
- 区块内容底：`--well: #110f18`
- 品牌强调：`--accent: #a98bff`，`--accent-strong: #c2acff`，`--accent-soft: #2a2145`
- 花瓣点缀：`--petal: #ff9272`
- For Later 淡化：`--later: #f2b24f`
- 风险操作：`--danger: #ff8490`

标志：

- 32×32 网格：圆角 8 的紫色底板 `#6c3ad6`；五片花瓣橙 `#ff8452` / 粉 `#f2557f` 交替（大图带由浅到深的渐变），黄色花心 `#ffd166` 带橙色细边和一个高光；右上角四角亮片 `#ffe2a8`，左下角粉色小点 `#ffb3c7`。
- 手绘感原则：保持小朋友画的稚嫩——花瓣大小、间距、轮廓都不均匀，花尖略歪，花心不是正圆；**不加纹理、描边、笔触或新元素**。形状由脚本生成的固定路径决定，修改时直接改 `dashboard.html` 里的路径。
- 页面内使用 `dashboard.html` 中的 `#logo-mark` symbol；工具栏图标为 `icons/icon-{16,32,48,128}.png`，修改标志时两处一起更新（16px 图标省略亮片、粉点和渐变，花瓣用纯色）。
- 空状态只用一句话，不放插画：三个区块的 `.module-empty` 只有 `<strong>` 标题 + 一行说明，清空后的标题用 `--text` 提亮。`dashboard.html` 里原来那四个 `#art-later` / `#art-open` / `#art-saved` / `#art-cleared` symbol 已删除，只剩堆肥提示卡的 `#art-compost`（由 `dashboard.js` 的 `art()` 用 `<use>` 引用）。
- 插画配色来自两条渠道：花与亮片直接写死标志色（`#ff8452` / `#f2557f` / `#ffd166` / `#ffe2a8` / `#ffb3c7`），叶子与土壤走主题变量，这样深色模式不会变成一团糊。新增的四个变量只服务于插画和堆肥提示卡：

  浅色 / 深色自动跟随：`--art-leaf: #6fb565`、`--art-leaf-light: #86c47a`、`--art-soil: #d99a5b`、`--art-soil-light: #f3c48e`。

## 3. 组件规则

- 区块圆角：14px。
- 网站卡片圆角：11px。
- 控件圆角：7–10px。
- 页面标题和摘要必须单行截断，防止卡片高度失控。
- favicon 优先使用网页资源；加载失败时显示网站名称首字母。
- 普通图标默认低强调，卡片 hover 后提高可见度。
- Undo 只使用常见撤销图标，辅助信息通过 tooltip 和 `aria-label` 提供。
- 批量危险操作不应使用大面积红色；仅在 hover、确认弹窗和最终确认按钮中加强风险提示。
- 简洁优先：一个强调色，区块图标与计数为中性灰；不给三个区块各配一种颜色。
- 顶栏 64px，只放 Logo、筛选、Jump to、设置齿轮；主题/音效/语言/快捷键收进设置面板（分段按钮 + 快捷键列表）。
- 区块标题与内容之间有分隔线，内容区使用 `--well` 底色；网站卡片默认无阴影，hover 时加深边框和阴影。
- 卡片标题栏：拖拽手柄（Open Tabs）、favicon、站点名、数量、站点级图标按钮（hover 出现）。没有底栏，超过 4 条时底部显示「+N more」。
- 行内操作按钮：静止时隐藏，hover 卡片 45% 透明度，hover 行 / 聚焦时 100%；`(hover: none)` 设备始终显示。
- 撤销：紧贴批量按钮的淡紫色胶囊「↶ Undo」，只在可撤销时出现；操作结果统一由右下角 toast 说明。
- For Later 时间淡化只用琥珀色细条 + 透明度/饱和度表达，同时有文字状态，不单靠颜色。
- Hover tooltip 延迟 350ms 出现，键盘聚焦时立即出现。
- 所有按钮/链接使用统一的 `:focus-visible` 描边；下拉控件以外框高亮表示聚焦。
- 状态胶囊（重复标签页 `3 dupes`、休眠 `Sleep idle`）是卡片标题栏里的低强调小标签，只在条件成立时出现；休眠标签行左侧有一条浅色虚线，表示内容已卸载。
- 已收起的窗口在 Open Tabs 区块顶部排成一行卡片，一行只放一组信息：站点名（超过 3 个用 `… +N`）、标签页数与收起时间、`Restore` 与删除。不用缩略图，也不用嵌套列表。
- 「堆肥」提示卡横跨全部列（`column-span: all`），配色走 `--art-soil*`，与 For Later 的琥珀淡化条区分开：前者是「该决定了」，后者是「搁置多久了」。

## 4. 英文 UI 词汇表

以下词汇已结合产品语境确认，修改时保持一致：

| 中文含义 | 使用文案 |
| --- | --- |
| 待处理网页 | `For Later` |
| 已打开的网页 | `Open Tabs` |
| 收藏的网页 | `Saved` |
| 全部处理完成 | `Complete all` |
| 关闭全部 | `Close all` |
| 移除全部收藏 | `Remove all` |
| 处理完成 | `Mark as done` |
| 稍后处理 | `Keep for later` |
| 收藏网页 | `Save page` |
| 撤销 | 图标 + tooltip `Undo` |

产品自身的按钮、说明、空状态和确认弹窗支持 English / 简体中文，所有文案集中在 `i18n.js`，新增文案必须同时补齐两种语言。网页标题、摘要、站点名属于网页内容，应保持其原始语言。

## 5. 可访问性

- 图标按钮必须提供 `aria-label`。
- 颜色不能成为唯一的状态提示。
- 所有主要操作应支持键盘聚焦。
- 遵循 `prefers-reduced-motion`，减少动画用户不播放过渡动画。
- Light/Dark 主题都应保持文字与背景的清晰对比。
- 空状态插画一律 `aria-hidden="true"`，信息全部由旁边的一行标题和一句说明承担。
- Logo 的姿态变化只写进 tooltip 与 `aria-label`，不依赖图形本身传达「标签页太多了」。
- 休眠、重复、收起、提醒都不靠颜色单独表达：胶囊有文字，提醒有 `Reminder came due` 状态行。

## 6. 动效与声音

- 单项完成：约 260ms，轻微缩小、强调色确认后退出。
- 单项关闭：约 220ms，向右短距离滑出。
- 批量操作：网站卡片按 42ms 间隔错峰退出，总等待时间设有上限。
- 撤销：卡片从上方轻微回弹进入。
- 收藏/稍后处理：图标短暂弹性放大并出现扩散圆环。
- 可交互控件在点击位置显示约 420ms 的八向 Canvas ClickSpark 火花线；关闭为风险色、完成为品牌紫、收藏为花瓣粉橙、撤销为深紫。
- 光标效果只在操作触发时出现，不使用持续跟随拖尾，避免长时间干扰。
- 声音控制必须保留 Off；默认 Subtle，Playful 仅提高音量和存在感。
- 不给搜索输入、刷新、页面切换等高频动作增加声音。
- 快捷键录制中的按钮有缓慢的呼吸光圈，提示正在等待按键。
- Logo 姿态切换约 550ms，五片花瓣各自微调角度与缩放（`open` → `droop` → `closed` 依次 20 和 40 个标签页为界）；亮片与粉点随姿态淡出。阈值 20 / 40 只是呼吸频率，不做数量统计展示。
- 清空庆祝：For Later 全部处理完时，Logo 跳动一次并让花瓣轻颤（约 950ms），同时播放 `bloom`——四音上行琶音（523 / 659 / 784 / 1046 Hz）加一个 1318 Hz 的收尾音。尊重 `sound` 设置与 `prefers-reduced-motion`；30 分钟内再次清空不重复庆祝，空状态在这段时间显示「All clear」。
- 休眠是一次性批量动作：播放一次 `fold`，不做逐条动效。
- 全部新增动效都只改变换与透明度，不触发重排；减少动态效果开启时直接跳到终态。
