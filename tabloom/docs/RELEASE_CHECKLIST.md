# Tabloom 测试与发布清单

每次准备交付或发布新版本时复制本清单，并逐项确认。

## 1. 静态检查

- [ ] `manifest.json` 是有效 JSON。
- [ ] `background.js`、`content-script.js`、`dashboard.js` 通过语法检查。
- [ ] Manifest 版本号已更新。
- [ ] CHANGELOG 已记录本次变化。
- [ ] 没有把密码、Token、个人浏览数据或测试数据提交进项目。
- [ ] 未引入不必要的权限和外部网络请求。
- [ ] 权限清单与功能匹配：`tabs`、`storage`、`contextMenus`、`sessions`、`scripting`、`alarms`（提醒与自动休眠）、`notifications`（提醒到期的系统通知）。

推荐命令：

```bash
node --check dashboard.js
node --check background.js
node --check content-script.js
python3 -m json.tool manifest.json >/dev/null
```

## 2. 安装与启动

- [ ] 能通过 `Load unpacked` 成功加载。
- [ ] 扩展管理页没有错误提示。
- [ ] 工具栏和扩展管理页显示手绘小花图标，Dashboard 标签页有 favicon。
- [ ] 点击工具栏图标能打开 Tabloom。
- [ ] 重复点击图标不会创建多个 Tabloom 页面，而是切换到已有页面。
- [ ] 首次安装能够自动打开管理页面。
- [ ] 在 `chrome://extensions` 的 service worker 里能查到 `tabloom:reminders` 和 `tabloom:sleep` 两个闹钟；停用再启用扩展后闹钟会重新注册。

## 3. Open Tabs

- [ ] 打开的普通网页会出现在列表中。
- [ ] 相同网站的标签页聚合在同一卡片。
- [ ] 标签页数量和窗口数量正确。
- [ ] 点击网页能切换到对应标签页和窗口。
- [ ] 单独关闭标签页后数量立即更新。
- [ ] `Close site` 只关闭当前网站标签页。
- [ ] `Close all` 会显示确认弹窗，并且不会关闭 Tabloom 自身和固定标签页。
- [ ] `Close site` 跳过固定标签页；全部是固定标签页时只提示不关闭。
- [ ] 方向键移动网站卡片后，焦点仍在同一个拖拽手柄上。
- [ ] 关闭后的 Undo 能重新打开 URL。
- [ ] 同一 URL 开了两次以上时，卡片标题栏出现 `N dupes` 胶囊；点击后多余副本关闭，固定标签页和当前正在使用的那个保留。
- [ ] 没有重复标签页时不显示胶囊，胶囊不是常驻元素。
- [ ] 多窗口时窗口标题栏出现 `Stash`：点击后该窗口标签页被存成一组并关闭，Open Tabs 顶部出现这组卡片，toast 提供撤销。
- [ ] 收起只影响被收起的那个窗口，不影响其他窗口；Tabloom 自身所在窗口不会被收起。
- [ ] 已收起卡片显示站点名、标签页数和收起时间；`Restore` 在新窗口打开全部标签页并移除该组；删除按钮移除该组但不打开网页。
- [ ] 刷新或重开 Tabloom 后收起组仍在。
- [ ] 手动 `Sleep idle` 只卸载闲置标签页，位置、顺序和标题保持不变，点击即可唤醒。
- [ ] 正在播放声音、固定、当前活跃的标签页不会被休眠；`chrome://` 页面被跳过。
- [ ] 休眠后 toast 提供撤销；撤销能重新加载这些标签页。
- [ ] 设置面板切换 Auto-sleep 为 `1 h idle` / `4 h idle` 后，`tabloom:sleep` 闹钟按新设置工作；切回 `Off` 后不再自动休眠。

## 4. For Later

- [ ] 从 Open Tabs 点击时钟可加入 For Later。
- [ ] 重复添加同一 URL 不会产生重复条目。
- [ ] 关闭原标签页后条目仍然存在。
- [ ] 点击已关闭条目能重新打开网页。
- [ ] `Mark as done`、`Complete site`、`Complete all` 行为正确。
- [ ] Complete all 直接执行，toast 和区块顶部都能撤销。
- [ ] 加入 3 天 / 7 天 / 14 天以上的条目依次加深淡化，hover 时恢复；超过一周时区块说明变为提醒。
- [ ] Undo 能恢复刚完成的条目。
- [ ] 条目上的提醒按钮提供 `Tonight` / `Tomorrow morning` / `Next Monday`；设置后状态行显示 `Reminder set for …`。
- [ ] 把系统时间调到提醒之后，一分钟内工具栏角标出现数字、状态行变为 `Reminder came due`，并收到系统通知。
- [ ] 点击系统通知会打开 Tabloom；多个提醒到期时通知与角标数量正确。
- [ ] `Clear` 能取消提醒，角标随之减少；`⌘Z` / `Ctrl+Z` 能撤销提醒的设置与取消。
- [ ] 有超过 14 天的条目时，For Later 顶部出现「堆肥」提示卡，说明多少个页面等了两周多。
- [ ] `Move to Saved` 把这些条目移入 Saved，`Let them go` 移除它们，两者都可撤销。
- [ ] `Not now` 关闭提示并写入 `compostAt`，一周内不再出现；清掉 `compostAt` 后重新出现。

## 5. Saved

- [ ] 从 Open Tabs 或 For Later 可以收藏。
- [ ] 重复收藏同一 URL 不会产生重复条目。
- [ ] 原标签页关闭后收藏仍保留。
- [ ] 单项 Remove 和 `Remove site` 正常。
- [ ] `Remove all` 直接执行，可撤销。
- [ ] 移除收藏不会关闭正在打开的标签页。
- [ ] Undo 能恢复刚移除的收藏。

## 6. 搜索与折叠

- [ ] 搜索标题、摘要、网站名称和 URL 都有效。
- [ ] 搜索同时作用于三个区块。
- [ ] `/` 能聚焦筛选框，`⌘K` / `Ctrl+K` 打开快速跳转。
- [ ] 设置面板：齿轮打开，点空白和 `Esc` 关闭，焦点回到齿轮；主题/音效/语言分段按钮立即生效。
- [ ] 修改快速跳转、筛选、撤销快捷键后立即生效，按键提示同步；冲突和 `⌘T`/`⌘W` 等会提示；恢复默认有效；单键快捷键在输入框里不触发。
- [ ] 浏览器全局快捷键显示正确，「去浏览器修改」能打开扩展快捷键页，修改后回到 Tabloom 显示更新。
- [ ] 无搜索结果时空状态正确。
- [ ] 三个区块都能独立折叠和展开。
- [ ] 行内操作按钮 hover 卡片才出现，键盘 Tab 聚焦时可见；站点级按钮在卡片标题栏右侧。
- [ ] 「重置顺序」只在拖拽过卡片后出现；撤销胶囊紧贴批量按钮。
- [ ] 刷新或重开 Tabloom 后折叠状态仍保留。

## 7. 视觉与文案

- [ ] 页面区块顺序为 For Later、Open Tabs、Saved。
- [ ] 桌面宽屏下区块为纵向排列，不是左右三栏。
- [ ] Light、Dark 和 System 主题都正确。
- [ ] Off 模式完全静音，Subtle 和 Playful 均能正常播放操作反馈。
- [ ] 完成、收藏、关闭、批量处理、撤销和折叠动效正确。
- [ ] 单项和批量操作在点击位置显示正确颜色的光圈/粒子，且不会阻挡点击。
- [ ] 第一次执行关闭操作时也能听到声音，不需要先触发其他音效。
- [ ] 批量处理只播放一次声音，没有逐条叠加。
- [ ] 系统开启减少动态效果时，操作不会因动画产生额外等待。
- [ ] 网页标题与摘要保持原语言。
- [ ] 产品界面没有混入中文操作文案。
- [ ] 长标题、长摘要和无 favicon 状态不破坏布局。
- [ ] 每张卡片最右侧操作按钮的 tooltip 完整显示，不被卡片边界或相邻卡片裁切。
- [ ] 键盘焦点清楚，图标按钮有 tooltip/aria-label。
- [ ] Logo 姿态：标签页 ≤20 为 `open`，21–40 花瓣下垂，>40 收拢；tooltip 与 `aria-label` 同步显示数量说明，不只看图形。
- [ ] 姿态切换是平滑过渡，不会在 20 / 40 边界上来回抖动；减少动态效果时直接跳到终态。
- [ ] For Later 全部清空时 Logo 跳动并播放 `bloom` 声音；30 分钟内再清空不重复；空状态显示「All clear / 全部清空」以及「小花向你道谢」。
- [ ] 三个区块的空状态各有一张手绘插画，且和品牌标志是同一种稚嫩线条：花瓣大小不一、茎是歪的，没有新增纹理、描边或笔触。
- [ ] 插画在 Light / Dark 下都清晰，叶子与土壤跟随主题变量；插画为 `aria-hidden`，不干扰读屏。
- [ ] 「堆肥」提示卡的配色与 For Later 的琥珀色淡化条能区分开。
- [ ] 提醒到期的条目有文字状态（`Reminder came due`），不是只变颜色。

## 8. 打包交付

- [ ] ZIP 中包含完整 `tabloom` 文件夹。
- [ ] ZIP 不包含 `.DS_Store`、临时文件或历史测试文件。
- [ ] `unzip -t tabloom-<版本>.zip` 检查通过。
- [ ] 安装说明与当前版本一致。
- [ ] 保留上一稳定版本 ZIP，以便回退。
