# Changelog

Tabloom 的重要变化记录在此文件中。版本号遵循语义化版本规则。

## [2.9.2] - 2026-10-22

### Changed

- **空状态只留文案**：三个区块为空时不再出现插画，只保留一句说明；「稍后看」刚清空时标题会提亮。四个空状态插画 symbol 一并删除，堆肥提示卡的插画保留。
- **提醒支持自定义时间**：提醒菜单在「今晚 / 明早 / 下周一」下面新增日期时间选择，可以指定任意时刻；已设过提醒的页面会预填原来的时间。日期框内方向键用于调整数字，Esc 关闭菜单。

### Removed

- 「手动排序」控件上的悬停提示「排序」去掉了，下拉框本身已经说明它是什么。

## [2.9.1] - 2026-10-22

### Changed

- **收起窗口移到 For Later，一次只收一个窗口**：入口从 Open Tabs 顶部的一排按钮改成 For Later 标题栏的「收起窗口」，点开后在弹出菜单里选要放一放的窗口（每个窗口显示标签页数量和站点图标），选定后关闭这些标签页、整组出现在 For Later 顶部。不再默认把所有窗口一次全部收起——收起意味着「这个项目我先放一放」，一次只处理一个窗口。固定标签页不会被关闭，只剩固定标签页的窗口在菜单里显示为不可选。恢复、删除和撤销的行为不变，命令面板里仍然可以直接收起某个窗口。
- **Logo 随标签页数量连续变化**：15 个标签页开始慢慢合拢、变蔫，30 个完全闭合，中间是连续的过渡而不是跳变；hover 依然显示当前状态。
- **清空 For Later 只留一句文案**：去掉了花瓣散开和跳动，只在空状态里放一句轻松的完成文案。

### Removed

- 页面点击时的烟花（click-spark）动效已移除。

## [2.9.0] - 2026-10-16

### Added

- **一键收起窗口（Stash）**：Open Tabs 区块顶部按浏览器窗口列出「Stash」按钮，一键把整个窗口的标签页存成一组并关闭。收起的组显示为胶囊标签（`3 tabs · stashed 2 days ago`），点 `Restore` 在新窗口一次性恢复，点删除图标移除整组。两种操作都能撤销；命令面板里也有对应的「收起窗口 N」「恢复「…」」命令。
- **重复标签页提示**：同一网址开了多份时，站点卡片数量旁出现「N dupes」小胶囊，点一下只关闭多出来的副本。保留优先级为：正在使用 > 固定 > 最近访问；固定标签页不会被关闭。命令面板的「关闭重复标签页」使用同一套逻辑。
- **闲置标签页休眠**：Open Tabs 顶部有「Sleep idle tabs」按钮，把闲置超过 30 分钟的标签页卸载以释放内存，位置不变，点击即恢复；被休眠的行显示「Sleeping」。设置面板新增 `Auto-sleep`（关闭 / 闲置 1 小时 / 闲置 4 小时），由后台 `chrome.alarms` 周期检查。只处理普通 HTTP(S) 页面，正在使用、固定、播放声音和不可自动卸载的标签页一律跳过。
- **For Later 提醒**：条目的时钟按钮变成下拉菜单，可选「今晚 / 明天早上 / 下周一」或清除。到期后该行显示「Reminder came due」并高亮，工具栏角标显示待处理数量，同时在系统通知里提醒一次（点通知直接打开 Tabloom）。打开 Tabloom 后角标清零。撤销也会一并撤销提醒。
- **「堆肥」提示**：有页面在 For Later 里躺过两周时，区块顶部出现一块堆肥插画和三个选择——`Move to Saved`（留作永久）、`Let them go`（放手）、`Not now`（下周再问）。选择后一周内不再打扰。
- **Logo 随状态变化**：顶栏小花会根据打开的标签页数量改变姿态——20 个以内盛开、超过 20 个花瓣下垂、超过 40 个收拢，hover 显示当前状态说明。
- **手绘空状态插画**：For Later / Open Tabs / Saved 的空状态各配一幅与 logo 同源的手绘图（嫩芽、花苞、花、土堆），配色跟随主题。
- **清空庆祝**：For Later 被清空时，logo 跳一下、花瓣散开，并播放一段四音上行的小旋律（Off 模式无声，「减少动态效果」时静态显示）。

### Changed

- For Later 空状态文案改为「All clear / For Later is empty. The flower says thank you.」，用于刚清空后的半小时内。
- 权限新增 `alarms`（定时检查提醒与自动休眠）和 `notifications`（提醒到期时的系统通知）。

## [2.8.1] - 2026-10-15

### Changed

- 品牌标志改为「稚嫩手绘」版：紫色底板不变，花朵取自小朋友的手绘画，粉橙两色五瓣花、黄色花心，右上一颗亮片、左下一颗粉色小点。花瓣大小、间距、轮廓都故意不均匀，保留手绘的歪扭感；不加纹理和描边。工具栏图标（`icons/`）、favicon 和页面左上角同步更新，16px 图标省略亮片和渐变。
- 点缀色 `--petal` 由金盏黄改为粉橙（浅色 `#ff7a59`、深色 `#ff9272`），用于收藏火花和网页内提示圆点；界面强调色仍是紫罗兰。

## [2.8.0] - 2026-10-15

### Added

- 新品牌标志：取自剪纸金盏花的五瓣花朵，紫色纸底、可可色花心，右上一颗青绿小点。扩展首次带上工具栏图标（16/32/48/128px，`icons/`），Dashboard 标签页也有了 favicon。
- 设置面板：顶栏齿轮按钮打开，集中放主题、音效、语言（分段按钮）和快捷键。点空白处或按 `Esc` 关闭，焦点回到齿轮。
- 页面内快捷键可修改：快速跳转（默认 `⌘K`）、筛选（默认 `/`）、撤销（默认 `⌘Z`）。点击快捷键后直接按新组合即可，`Esc` 取消；与其他快捷键冲突、或被浏览器占用（如 `⌘T`、`⌘W`）时会提示；可一键恢复默认。修改后搜索框、跳转按钮、toast 上的按键提示同步更新，并同步到其他已打开的 Tabloom 标签页。
- 浏览器全局快捷键（打开 Tabloom、留作稍后看、保存）在设置面板中显示当前绑定，并提供「去浏览器修改」入口；从浏览器设置页回来后自动刷新显示。

### Changed

- 品牌色改为紫罗兰（浅色 `#6c3ad6`、深色 `#a98bff`）作为唯一强调色；金盏色 `--petal` 只用于收藏火花和网页内提示圆点。页面底色、线条和文字改为带一点紫调的中性灰。
- 视觉减法：三个区块不再各用一种身份色，区块图标和计数改为中性；顶栏降到 64px；区块标题更紧凑；卡片默认不显示行内操作按钮，hover 卡片时淡出现、hover 行或键盘聚焦时完全显示。
- 顶栏只保留 Logo、筛选框、快速跳转和设置齿轮；移除刷新按钮（页面会随标签页变化自动刷新，命令面板里仍有「刷新」）。
- 网站卡片去掉底栏：`Complete site` / `Close site` / `Remove site` 改成卡片标题栏右侧的图标按钮，hover 卡片时出现；只有超过 4 条时才在底部显示「+N more」。
- 区块右上角的操作反馈文字去掉（toast 已经说明发生了什么），撤销改为紧贴批量按钮的「↶ 撤销」小胶囊。
- Open Tabs 的排序控件改为图标 + 下拉；「重置顺序」只在存在自定义拖拽顺序时出现。
- 命令面板「自定义键盘快捷键」改为打开设置面板的快捷键区域。
- 收集成功的工具栏角标改为品牌紫。

## [2.7.0] - 2026-10-15

### Added

- For Later 时间淡化：页面按加入时间分四档，左侧琥珀色细条逐级加深、内容逐级变淡，hover 时恢复；状态行显示加入时间（如「5 天前加入」）。有页面搁置超过一周时，区块说明会改为提醒。
- 已打开的固定标签页在行内显示「已固定」。

### Changed

- `Close all`、`Close site` 和命令面板的「关闭某网站全部标签页」不再关闭固定标签页；确认弹窗和提示会说明保留了几个。单独关闭某个固定标签页仍然可以。
- `Complete all`、`Remove all` 不再弹确认，直接执行并提供撤销；只有关闭标签页仍会确认。
- 视觉精修：三个区块使用各自的身份色（稍后看琥珀、已打开紫、已保存绿）；区块内容区加底色和分隔线，卡片加轻阴影与 hover 反馈；小号文字放大一档，次要文字对比度提高到 4.5:1；tooltip 悬停延迟出现；统一键盘焦点描边；弹窗进场动画。

### Fixed

- 键盘方向键排序网站卡片、完成或关闭某一行后，焦点不再丢失：会回到同一元素，或落到相邻一行。
- 浏览器重启后残留的 `meta:*` 元数据会被清理；标签页 id 复用时不会显示别的网页的摘要。
- 窄窗口下确认弹窗的「取消」按钮被误隐藏。

## [2.6.0] - 2026-10-14

### Added

- 界面支持 English / 简体中文。默认跟随浏览器语言，可在顶栏地球图标的下拉中切换；选择会保存在本地，并同步到其他已打开的 Tabloom 标签页。
- Dashboard、右键菜单标题、网页内确认提示共用同一份文案表 `i18n.js`，切换语言后三处同时生效，无需重新加载扩展。
- 网页标题、摘要等页面内容始终保持原语言，不做翻译。

### Fixed

- 用快捷键或右键菜单收集后，工具栏角标和网页提示有时不出现：扩展安装或重新加载前就已打开的标签页没有内容脚本。现在会按需注入后重试；受限页面（如 `chrome://`、应用商店）至少仍会显示角标。
- 角标和网页提示改为互不影响，其中一个失败不会连带另一个。
- 后台被快捷键唤醒时，第一条提示可能使用系统语言而非用户选择的语言。

### Changed

- 页面无标题或无摘要时，占位文案在显示时生成，不再写入存储，切换语言后也能正确显示。
- 点击特效的颜色改由按钮自身声明，不再依赖英文按钮文字判断。
- 新增权限：`scripting`。

## [2.5.0] - 2026-10-14

### Added

- 全局快捷键：`Alt+Shift+T` 打开 Tabloom，`Alt+Shift+L` 把当前页加入 For Later，`Alt+Shift+S` 收藏当前页；可在浏览器扩展快捷键页面自定义。
- 右键菜单：在网页或链接上右键即可 Keep for later / Save，无需切回 Dashboard。
- 收集成功后工具栏图标显示短暂角标，并在网页右下角显示不受页面样式影响的确认提示。
- `⌘K` / `Ctrl+K` 命令面板：跨 Open Tabs、For Later、Saved 模糊搜索并直接跳转；`↑↓` 选择，`↵` 打开，`⌘↵` 加入 For Later / 标记完成，`⌘S` 收藏，`⌘⌫` 关闭或移除。
- 命令面板内置命令（输入 `>` 只看命令）：关闭重复标签页、关闭某网站的全部标签页、折叠/展开全部区块、切换主题、开关声音、刷新、自定义快捷键。
- Toast 内联 Undo 按钮，持续 6 秒，悬停时暂停消失；`⌘Z` / `Ctrl+Z` 撤销最近一次操作。
- 加入 For Later / Saved 也可以撤销。

### Changed

- 撤销关闭的标签页优先通过 `chrome.sessions` 恢复，保留前进/后退历史并回到原窗口；浏览器不再记得的标签页才按 URL 重新打开。
- 页面内筛选框的快捷键改为 `/`，`⌘K` 让给命令面板。
- 后台通过快捷键或右键菜单加入的页面会实时同步到已打开的 Dashboard。
- 存储写入只更新发生变化的字段，避免 Dashboard 覆盖后台刚写入的数据。
- 收集条目一律使用独立 UUID；旧数据中重复或数值型 id 会在加载时自动修复，避免移除一条时误删另一条。
- 新增权限：`contextMenus`、`sessions`。

## [2.4.0] - 2026-07-21

### Added

- Open Tabs 网站卡片支持拖拽调整顺序，并将手动顺序保存在本地。
- 增加 Manual order、Most tabs、Recently active 和 Site name 四种排序模式。
- 拖拽手柄支持方向键移动，搜索状态下禁用排序以避免部分结果造成顺序误解。
- 增加 Reset order 操作，新出现的网站在手动排序末尾追加。

## [2.3.0] - 2026-07-17

### Added

- 网站卡片超过 4 条网页时默认收起，使用 `+ N more` 展开并通过 `Show less` 恢复。

### Changed

- 三区块内部从等高行 CSS Grid 改为响应式多列瀑布流。
- 桌面端三列、中等宽度两列、窄屏单列，卡片在各列中紧密排列。
- 消除不同网页数量造成的整行留白，同时避免固定高度和卡片内滚动条。

## [2.2.0] - 2026-07-15

### Added

- 将点击反馈升级为基于 Canvas 的 ClickSpark 火花线特效。
- 为普通操作、完成、收藏、关闭和撤销提供语义化火花颜色。
- 支持高分屏渲染、窗口尺寸变化和键盘触发位置回退。

### Changed

- 使用按需 `requestAnimationFrame` 绘制替换原有 DOM 光圈/粒子，减少临时元素和持续动画开销。
- 点击火花扩展到按钮、链接、选择器和网页主操作区域。

## [2.1.2] - 2026-07-14

### Changed

- 提高 Subtle 和 Playful 两档声音的整体增益。
- 进一步加强单项关闭和批量关闭的瞬态、低频和收尾声音。

### Fixed

- 修复网站卡片最右侧操作按钮的 tooltip 被卡片边界裁切的问题。
- 行内 tooltip 改为向上弹出，最右侧提示向左对齐，并在 hover/focus 时提升卡片层级。

## [2.1.1] - 2026-07-14

### Added

- 完成、收藏、关闭、撤销和折叠等关键操作的点击位置光圈与粒子反馈。
- 为键盘触发操作提供以控件中心为起点的光标效果。

### Fixed

- 提前在用户按下指针时初始化 Web Audio，修复第一次关闭网页或确认批量关闭后没有声音的问题。
- 加强关闭和批量关闭音效的瞬态与音量，使 Subtle 模式下仍能清晰感知。

## [2.1.0] - 2026-07-14

### Added

- `Off`、`Subtle`、`Playful` 三档声音设置，默认使用 Subtle。
- 完成待处理、加入收藏、加入稍后处理、关闭标签页、网站级处理、批量清理、撤销和折叠的触感动效。
- 基于 Web Audio API 的本地声音反馈，不增加网络请求或音频素材依赖。
- 批量操作的错峰卡片退出效果和单次组合声音。
- 对系统“减少动态效果”设置的支持。

### Changed

- 声音偏好保存到本地，并兼容 2.0.0 版本已有数据。

## [2.0.0] - 2026-07-14

### Added

- 全新的 Tabloom 桌面端管理页面。
- For Later、Open Tabs、Saved 三个纵向业务区块。
- 按网站聚合标签页和网页 favicon/logo。
- 读取网页自身的标题、description 摘要与站点名称。
- 标签页切换、单项关闭、网站级关闭和 Close all。
- 可在标签页关闭后继续保留的 For Later。
- 本地持久化 Saved 收藏。
- 搜索、区块折叠、批量确认、单步撤销和操作反馈。
- System、Light、Dark 三种主题模式。

### Changed

- 产品从旧版 `Tab Atlas / 标签星图` 更名为 `Tabloom`。
- 从 420px 工具栏弹窗改为完整的浏览器桌面页面。
- 产品 UI 统一使用英文，网页内容保持原始语言。

### Known limitations

- 受保护的浏览器内部页面无法读取 description。
- 关闭标签页后的撤销不能恢复原浏览历史。
- 当前数据只保存在本地，不支持跨设备同步。
