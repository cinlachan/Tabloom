# Tabloom

> Keep tabs clear. Save what matters.

Tabloom is a local-first tab manager for Chrome and Microsoft Edge. Organize open tabs, keep pages for later, and save what matters.

## Install

Download **[tabloom.zip from the latest release](https://github.com/cinlachan/tabloom/releases/latest)**, extract it, then choose **Load unpacked** on your browser's extensions page with Developer mode enabled. Select the extracted folder containing `manifest.json`.

If you clone this repository, load the **`tabloom/`** subfolder as the extension.
